# 첫 화면 영상 연결

사용자가 제공한 `KLeague_2026_Web_Hero2.mp4`를 `hero.mp4`로 복사해 연결했습니다. 원본은 변경하지 않았습니다.
1280×720, 30fps, 40.6초, 2,099,249바이트입니다. `hero-poster.jpg`는 영상 1초 지점에서 추출했습니다.
BEPRO의 영상·이미지·브랜드 자산을 복사하지 않았습니다.

영상을 교체할 때 이 폴더에 `hero.mp4`를 저장하고 `public/data/sample-data.json`의 `heroMedia`를 변경합니다.

```json
"heroMedia": {
  "videoSrc": "/media/hero.mp4",
  "posterSrc": "/media/hero-poster.jpg"
}
```

포스터가 없으면 `posterSrc`는 `null`로 둡니다. 영상이 없으면 `videoSrc`도 `null`이며 잘못된 경로를 요청하지 않습니다. 파일명은 실제 파일과 일치시킵니다. 샘플 재생성 스크립트는 이 폴더의 hero.mp4와 hero-poster.jpg 존재 여부에 따라 경로를 연결합니다.

- MP4(H.264)를 권장하며 WebM도 해당 브라우저가 지원하면 연결할 수 있습니다.
- 배경용이므로 무음·반복·인라인 재생합니다. 음성에 필수 정보를 담지 않습니다.
- 화면을 채우는 `object-fit: cover`를 사용하므로 모바일에서는 좌우가 잘릴 수 있습니다. 현재 영상은 오른쪽 구단 로고를 고려해 모바일에서 가로 위치를 74%로 지정했습니다.
- 사용자가 영상 재생/일시정지를 선택할 수 있습니다. 모션 감소 설정에서는 자동 재생하지 않습니다.
- 영상 오류·자동 재생 제한이 있어도 제목과 시작 버튼은 사용할 수 있습니다.
- 빌드 미리보기는 파일 연결 후 `npm run build:bundle`을 다시 실행합니다.

영상에는 2026/29구단 표기가 포함되어 있으며, 앱의 분석 데이터는 기존 2025 합성 샘플을 유지합니다.
