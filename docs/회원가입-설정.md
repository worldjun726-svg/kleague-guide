# 회원가입 개편 설정 (이메일·비밀번호 · 카카오 · Google)

사이트 코드는 준비되어 있습니다. 아래 설정을 Supabase·카카오·Google 대시보드에서 해 주세요.
**1번(SQL)과 2번(이메일)을 먼저 하고 사이트를 배포**해야 회원가입이 막히지 않습니다. 3·4번(카카오·Google)은 나중에 해도 되며, 그전까지 버튼을 누르면 "아직 연결되지 않은 로그인 방식이에요" 안내가 나옵니다.

Supabase 프로젝트 주소: `https://dynsydeyseffhiwabvam.supabase.co`
소셜 로그인 콜백 주소(카카오·Google 양쪽에 등록): `https://dynsydeyseffhiwabvam.supabase.co/auth/v1/callback`

## 1. 프로필 표·닉네임 중복 확인 (SQL)
1. Supabase → **SQL Editor** → New query
2. 저장소의 `supabase/auth-upgrade.sql` 내용을 통째로 붙여 넣고 **Run**
3. **Table Editor**에 `profiles` 표가 생기면 성공입니다.

이미 가입한 회원(예전 이메일 링크 방식)은 프로필이 자동으로 만들어지고, 다음 로그인 때 약관 동의를 한 번 받습니다.

## 2. 이메일 + 비밀번호
Supabase → **Authentication → Sign In / Providers → Email**
- **Enable Email provider**: 켜기
- **Confirm email**: 켜기 (가입하면 인증 메일을 받아 링크를 눌러야 가입 완료)
- **Minimum password length**: `8` (사이트도 8자 이상·영문·숫자를 요구합니다)

**Authentication → URL Configuration**의 Redirect URLs에 사이트 주소가 이미 들어 있는지 확인합니다.
- `https://worldjun726-svg.github.io/kleague-guide/`
- `http://127.0.0.1:4173/`, `http://localhost:4173/`

예전에 이메일 링크로 가입한 회원은 비밀번호가 없습니다. 로그인 창의 **비밀번호를 잊으셨나요?**에서 처음 비밀번호를 만들 수 있습니다.

> 무료 요금제의 기본 메일 발송은 시간당 몇 통으로 제한됩니다. 가입자가 늘면 **Authentication → Emails → SMTP Settings**에서 메일 발송 서비스(예: Resend)를 연결하세요.

## 3. 카카오 로그인 (2026년 11월 카카오 콘솔 메뉴 기준)
1. [Kakao Developers](https://developers.kakao.com) 오른쪽 위 **로그인**
2. 위쪽 **앱** → **앱 만들기**: 앱 아이콘(선택), 앱 이름 `K LEAGUE GUIDE`, 회사 이름(개인이면 본인 이름), 카테고리(스포츠 등),
   **앱 대표 도메인** `https://worldjun726-svg.github.io` → **저장**
3. 만든 앱 클릭 → **앱 설정 → 앱 → 플랫폼 키** → **REST API 키** 항목을 클릭해 편집 화면으로
   - **카카오 로그인 Redirect URI**에 `https://dynsydeyseffhiwabvam.supabase.co/auth/v1/callback` 입력
   - **카카오 로그인 Client Secret 코드**: 값을 복사해 두고 **활성화** 상태로
   - 오른쪽 아래 **저장**
   - 같은 화면 위쪽의 **REST API 키** 값도 복사해 둡니다(= Client ID)
4. **제품 설정 → 카카오 로그인 → 일반**: **사용 설정 상태 ON**
5. **제품 설정 → 카카오 로그인 → 동의항목**: **닉네임(profile_nickname)**, **프로필 사진(profile_image)** 설정
   - 이메일(account_email)은 비즈 앱에서만 쓸 수 있어서 이 사이트는 쓰지 않습니다.
6. Supabase → **Authentication → Sign In / Providers → Kakao**
   - **Enable Sign in with Kakao** 켜기
   - **REST API Key**(Client ID) = 3번의 REST API 키, **Client Secret Code** = 3번의 Client Secret
   - **Allow users without an email** 켜기 (이메일 동의항목을 쓰지 않으므로 필수)
   - **Save**

## 4. Google 로그인
1. [Google Cloud Console](https://console.cloud.google.com) → 프로젝트 만들기
2. **API 및 서비스 → OAuth 동의 화면**: 외부(External), 앱 이름·지원 이메일 입력
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: 웹 애플리케이션
   - 승인된 리디렉션 URI: 위 콜백 주소
4. 만들어진 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 Supabase → **Authentication → Sign In / Providers → Google**에 넣고 켜기

## 화면 흐름
- **회원가입**: 이메일 → 비밀번호(규칙 실시간 표시) → 비밀번호 확인 → 닉네임(중복 확인) → MY 팀(선택) → 약관 동의 → 인증 메일 → 링크 클릭으로 가입 완료
- **로그인**: 이메일·비밀번호, 또는 카카오·Google 버튼
- **비밀번호 찾기**: 이메일 입력 → 재설정 메일 → 링크로 들어오면 새 비밀번호 입력 창
- **카카오·Google 첫 로그인**: '가입 마무리' 창에서 닉네임(중복 확인)·MY 팀·약관 동의
- **약관**: `#/terms`, `#/privacy` (초안 — 운영자 정보와 문구는 운영 전에 확정)
